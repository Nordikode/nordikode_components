# Tone of voice

> **Status: utkast.** Forslag fra design-auditen 2026-08-18; vedtas i fase 4.

## Stemmen vår

Vi skriver til travle håndverkere og bedriftsledere: **direkte, konkret og
rolig**. Du-form, aldri «De». Ingen «Vennligst» — si heller hva som skal skje.

## Foreslåtte regler

| Område | Regel | Eksempel |
| --- | --- | --- |
| Feilmeldinger | «Kunne ikke X.» — fortid, punktum | «Kunne ikke lagre kunden.» |
| Knapper | Imperativ, gjør-ord | «Send tilbud», ikke «Sending» eller «Ferdig» |
| Ellipse | `…` (U+2026), *uten* mellomrom foran | «Lagrer endringer…» |
| Tankestrek | `—` for parentetiske innskudd | |
| Sitattegn | `«»` rundt brukerverdier | «Slette «Bad 2. etg.»?» |
| Store bokstaver | Setningsstil, aldri Title Case | «Velg firma», ikke «Velg Firma» |
| du/dere | «du» til håndverkeren, «dere» på UE-flaten | skriv regelen der begge flater møtes |
| Plassholdere | `{count}` (ikke `{n}`), `{company}` (ikke `{tenant}`) | |

## Antimønstre (funnet i auditen)

- «Kan ikke lagre grunnleggende innstillinger» — presens + manglende punktum
- «Vennligst skriv inn en e-postadresse.» — translationese
- Tre ellipsestiler i samme app
- du og dere blandet i samme avsnitt
